
# DevSync

A VS Code collaboration extension that connects team discussion to the code changes happening around it.

DevSync brings chat, project activity, commits, pull requests, and a lightweight architecture map into one timeline inside VS Code.

The goal is to make it easier for teammates to understand what changed, when it changed, and why it matters without jumping between chat and Git tools.

## Hackathon MVP

This repository's current scope is a focused demo for a four-person team:

- Project chat in a VS Code Webview
- Member-joined timeline events
- Commit activity linked to the project timeline
- Click-through to a commit's changes
- A generated architecture map with export
- Realtime updates for chat and project events
- Optional Gemma-powered architecture explanation

The MVP is intentionally not a production collaboration platform.

## Proposed Tech Stack

- VS Code Extension: TypeScript + VS Code Extension API
- Webview UI: React + TypeScript + Vite
- Backend: Node.js + TypeScript + Express
- Realtime: Socket.IO
- Database: SQLite
- ORM: Prisma
- Git integration: VS Code Git API with Git CLI fallback
- Architecture visualization: React Flow
- Architecture scanning: TypeScript compiler API
- Optional AI: Gemma through local Ollama or a configured hosted provider

These are proposed implementation choices for the hackathon. Confirm package versions and final implementation before coding.

## MVP Principles

1. Timeline truth first: distinguish Git timestamps from when DevSync detected or linked an event.
2. Deterministic core: chat, timeline, Git links, and architecture graph must work without AI.
3. Small-team reliability: optimize for a reliable four-person demo.
4. No secret collection: do not store credentials, tokens, or unrelated editor activity.
5. Explainable AI: if Gemma is enabled, it explains a graph generated by code; it does not invent the graph.
